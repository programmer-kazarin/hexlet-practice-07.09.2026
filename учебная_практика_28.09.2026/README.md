## Разработка интерфейса истории реализации продукции
* schema_fix.sql - для БД из предыдущих заданий - изменился тип для рейтинга, добавились констрейнты.
* schema.sql - для новой БД.
* partner_history.html - страница PartnerHistoryWindow с заголовком «CRM: История реализации продукции — [партнёр]».

* db.py - добавлены get_partner_sales_history с JOIN-запросом.
* server.py - добавлены маршруты /api/partners/<id>/history и /partners/<id>/history.
* index.html - добавлены кнопки Редактировать (раньше было по клику) и История продаж.
* app.js - клик по карточке теперь выбирает партнёра, редактирование открывается двойным кликом или кнопкой Редактировать, а кнопки переходят на страницы редактирования и истории с partner_id.
- style.css - добавлены стили выбранной карточки, таблицы истории.
